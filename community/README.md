# 社区贡献

这里主要收两类东西，门槛都很低：

1. **作品**：你用这套 runtime 做出的视频，连同提示词和复现信息。
2. **设备报告**：你在自己设备上做的适配、优化或跑测记录。

除此之外，性能优化、代码改进、工具和测试也同样欢迎；分类只是方便索引，不是范围限制。

创作归作者。我们不限制题材、风格、提示词格式，也不要求授权声明；只要能提供**大致可复现**的内容就够了。视频是加分项，不是必填。

## 作品

```
community/works/<你的目录名>/
  README.md      # 自由格式：做了什么、怎么跑出来的
  case.json      # 可选，结构化复现信息
  video.mp4      # 可选
  inputs/        # 可选：首尾帧、参考图
```

`case.json` 只求能复现，字段都可以缺：

```json
{
  "prompt": "提示词原文",
  "model": "H3 Turbo",
  "variant": "fl2va",
  "steps": 4,
  "duration_s": 5,
  "resolution": "832x480",
  "fps": 24,
  "seed": 4106,
  "strategy": "fast",
  "inputs": ["first.png", "last.png"],
  "command": "可选"
}
```

复现不要求同设备、同哈希、同精度，能大致对上就够。

## 设备报告

```
community/devices/<你的目录名>/
  README.md      # 设备、试了什么、结果、怎么复现
  profile.json   # 可选，结构化数据
```

`README.md` 建议写：设备配置（可脱敏）、任务、试过的策略、结果、复现步骤、哪些没验证。`profile.json` 可以放阶段耗时、峰值、kernel 命中，但不强制。

## 两条硬线

- 不放个人隐私、密钥、主机名、内网 IP、本地绝对路径。
- 不放超大文件；大视频用外链。

这两条之外，没有别的门槛。

## 提交方式

直接开 PR。是否合并、是否展示，维护者后续决定；社区条目不是官方样片，也不是官方验收。
